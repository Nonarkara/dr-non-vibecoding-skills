# The vibe foundation

> Classify the work, match the person, write the pass line, then build. The library is what you load after that, not instead of that.

A beginner can follow [`START-HERE.md`](../START-HERE.md) and ignore this file. This playbook is why the gate is shaped the way it is, and what we refused to add.

## What went wrong when there was no gate

The library was already large. An agent landing in it could load a design essay for a one-file toy, or ship a civic alert with the ceremony of a toy. Both have happened in the practice this repo records.

- An invented "how often projects die" figure was written into the README and then rejected. The rule that survived is in the relay ledger: no invented numbers. [`definition-of-done`](../skills/definition-of-done/SKILL.md) is that rule applied to a coding session. A claim needs a command you ran.
- "Done" on localhost is the failure [`ship-discipline`](../skills/ship-discipline/SKILL.md) names. The foundation does not replace that skill. It tells you when the live check is required: production and civic, not a page you will delete tonight.
- A secret in a place an agent can read is the failure [`secrets-management`](../skills/secrets-management/SKILL.md) and [`risk-posture`](../skills/risk-posture/SKILL.md) already own. The baseline says the scanner's printout is `file:line` and a rule id.
- This README itself carried a leftover merge marker and three different skill counts at once. `scripts/validate_repo.py` now rejects a conflict marker. The counts stay on `make validate`.

None of those is a statistic about the industry. They are defects this repo has already paid for.

## The walk

1. Say the class out loud. Throwaway, prototype, production, civic. [`proportionality`](../skills/proportionality/SKILL.md).
2. Say whether the person is learning, producing, or playing. [`user-need`](../skills/user-need/SKILL.md). A lesson that dumps a finished app has missed. A "fix it" that opens with a lecture has missed.
3. Write the sentence that will be false if you fail. Then edit.
4. Build only what that class needs. [`ponytail`](../skills/ponytail/SKILL.md) on the happy path. Extra weight on the failure path when the class is civic: expiry, a second source, a person who notices, a restore you have dated.
5. Run the short slop card. The long rules were already in the repo. [`anti-slop`](../skills/anti-slop/SKILL.md) is the index, not a fifth copy.
6. Turn on the security row for that class. Report-only first. [`security-baseline`](../skills/security-baseline/SKILL.md).
7. Leave a command someone else can run. [`reproducible-result`](../skills/reproducible-result/SKILL.md).
8. Paste the output. Then the four buckets.
9. Walk [`vibe-review`](../skills/vibe-review/SKILL.md) before you hand it back.

## What we did not vendor

Public skill repos are full of packs that want to be installed whole. We read a handful and took one behavior from each. [`CREDITS.md`](../CREDITS.md) names the licence and the cut.

Context Mode is the one to be careful with. It is Elastic License 2.0: source-available, not OSI open source. It is credited from [`context-economy`](../skills/context-economy/SKILL.md). Its text and its hooks are not in this repo. Headroom is Apache-2.0 and is credited the same way, without their savings figures and without their installer.

stop-slop is MIT. We took the prose pass and left the bans that fight this repo's voice. The catalog itself says those bans are opinionated.

OWASP and Google's review guide are Creative Commons. We paraphrased. We did not copy.

## How you know the gate is working

A throwaway dice page does not grow a workflow, a design system, or Dependabot.

A flood alert does not ship because the page rendered once. It has an expiry, a second source, a scan that does not print secrets, and a check aimed at the failure a resident would feel.

The agent can point at the class, the mode, the pass sentence, and the command output without opening a second pack.
