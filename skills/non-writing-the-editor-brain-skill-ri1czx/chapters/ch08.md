# ch08 — Per‑Post Patterns: blunt_open, hook_then_turn, image_then_argument, etc.

> Provides a catalog of reusable patterns derived from the blog posts, explaining when each is appropriate.

The blunt_open pattern starts with a stark claim and is best for opinion pieces or when the writer wants immediate impact. Hook_then_turn begins with a vivid image, then pivots to a personal reflection, suitable for narrative essays. Image_then_argument uses a visual description as the sole opening, then builds the argument around that image, ideal for descriptive essays. Stream_consciousness lets the writer write uninterrupted for a set time before inserting theory, perfect for reflective journals. Before_after frames a transformation, useful when describing a habit change or a new perspective. Thinker_load drops a philosopher’s name early to set the intellectual tone, appropriate for essays that rely on theoretical grounding.
