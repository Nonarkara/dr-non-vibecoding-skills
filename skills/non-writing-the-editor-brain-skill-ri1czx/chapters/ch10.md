# ch10 — Cheatsheet: Index‑Card Rules for Instant Recall

> Collects short imperative rules that an editor can glance at while rewriting to stay true to Non’s style.

The cheatsheet condenses the do/don’t list into bite‑size commands. Each rule is categorized for quick lookup, covering design, writing, process, and general habits. By keeping these rules visible, an editor can instantly check whether a sentence aligns with Non’s voice before finalizing the rewrite.
