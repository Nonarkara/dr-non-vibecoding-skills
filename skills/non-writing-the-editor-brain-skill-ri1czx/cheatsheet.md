# Cheatsheet

Imperative decision rules from the source, grouped by category. Each is the kind of sentence you would write on an index card.

## writing

- Start with a blunt claim or vivid image; never begin with a generic statement.
- Insert a short quote or thinker name within the first paragraph.
- End with a quiet aphorism or an open‑ended question, not a summary.
- Never use generic transitions like "however"; replace them with personal asides.
- Add a short imagined dialogue to dramatize internal conflict.
- Never hide the writer’s voice behind neutral tone; keep the personal pronoun present.

## process

- Write a 10‑minute uninterrupted stream before adding any analysis.
- When describing a change, use the before/after pattern.
- Use the bike metaphor to illustrate personal transformation or focus.

## style

- Use dashes, ellipses, or commas to create pauses that mimic breathing.

## design

- Contrast two opposing ideas in the same paragraph to create tension.

## life

- Reject possessive language in love essays; frame love as mutual and non‑owning.

## general

- If the piece feels too polished, add a minor grammatical stumble to restore rawness.
- Close with a dash or ellipsis to leave the reader hanging.
- When in doubt, ask yourself: "Does this sentence sound like me talking to myself?"

## code

- When referencing a thinker, keep the citation brief—just the name and a short phrase.
