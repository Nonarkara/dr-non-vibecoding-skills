# ch08 — Schemas and Compactness

> Explains how to use existing mental schemas to make new ideas easy to grasp, and how to combine core and compactness into a proverb‑like message.

A schema is a packet of generic knowledge stored in memory—such as the concept of a grapefruit—that allows us to understand new information quickly by analogy. When you say a pomelo is a “supersized grapefruit,” you invoke the grapefruit schema and only need to specify the difference (size). This makes learning faster and memory stronger than listing all attributes from scratch. To create a compact yet meaningful message, combine the core idea with a familiar schema: the core provides the essential truth, the schema provides the familiar anchor, and compactness makes it short enough to remember. Proverbs work this way: “A bird in the hand is worth two in the bush” ties the core (don’t risk a sure thing for speculation) to the familiar image of birds. The Visual Proverb of the Palm Pilot team used a wooden block the size of the device to remind engineers to avoid feature creep—seeing the block triggered the schema of simplicity. When crafting a message, ask: *What familiar concept can I use as a schema?* Then express the core as a modification of that concept, and trim the language to its most essential form. The result is a message that is both easy to grasp and hard to forget.
