# Glossary

Terms and named ideas from the source, anchored to the chapter that explains them.

| Term | Definition | Chapter |
| --- | --- | --- |
| **Commander's Intent** | A crisp statement of an operation's goal that aligns action without detailed orders. | ch01 |
| **Curse of Knowledge** | The inability to remember what it was like not to know something, hindering clear communication. | ch07 |
| **SUCCESs** | The acronym for Simple, Unexpected, Concrete, Credible, Emotional, Stories—the traits of sticky ideas. | ch02 |
| **Gap Theory** | The idea that highlighting missing information creates curiosity that motivates people to seek closure. | ch02 |
| **Concrete** | Language that invokes sensory details or specific examples, making ideas easy to picture and remember. | ch03 |
| **Credible** | Believable through authority, anti‑authority, vivid details, or a standout example that stands for the whole. | ch04 |
| **Emotional** | Evokes feeling by appealing to self‑interest, identity, or emotions like resentment, driving care and action. | ch05 |
| **Story** | A narrative that lets the audience mentally rehearse a situation, preparing them to act in real life. | ch06 |
| **Schema** | A packet of generic knowledge in memory that helps us understand new concepts by analogy. | ch08 |
| **Proverb** | A short, memorable saying that captures a core truth drawn from experience. | ch08 |
| **Forced Prioritization** | The practice of identifying the single most important point and eliminating competing details. | ch01 |
| **Anti‑Authority** | A credible source who lacks formal authority but has lived experience relevant to the message. | ch04 |
| **Sinatra Test** | If you can make it work in one demanding case, it proves the idea works anywhere. | ch04 |
| **Story Spiral** | A simple story structure: character with goal, obstacle, struggle, resolution that illustrates the core message. | ch06 |
| **Core** | The essential, singular idea that must be communicated for the message to have impact. | ch01 |
| **Compact** | Short enough to be easily remembered, while still conveying the core idea. | ch08 |
| **Unexpected** | Violates expectations to grab attention and create a curiosity gap. | ch02 |
| **Idea Clinic** | A before‑and‑after exercise that improves a message using the SUCCESs checklist. | ch09 |
| **Teenager Test** | Explaining an idea to a novice to check whether the Curse of Knowledge has been overcome. | ch07 |
| **Visual Proverb** | A tangible object that reminds a team of a core simplicity goal, like the Palm Pilot wooden block. | ch08 |
