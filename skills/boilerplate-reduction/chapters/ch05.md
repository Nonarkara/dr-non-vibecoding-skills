# ch05 — Automating Boilerplate Reduction

> Introduce simple scripts and tools that can automate detection and replacement of repeated filler.

Manual scanning works for short drafts, but larger documents benefit from automation. Common tools include regular‑expression search in editors, command‑line utilities like `awk` or `sed`, and small Python scripts that count sentence occurrences and replace them with tokens. A typical script reads the file, builds a frequency map of each line, and rewrites the file keeping only the first instance of any line that appears more than three times, substituting the rest with a token. The script also adds a comment block listing which lines were replaced, aiding future reviewers. By integrating such a script into your workflow, you can process dozens of pages in seconds, ensuring consistency and freeing mental bandwidth for higher‑level editing.
