# ch04 — Verifying Logical Flow After Cleanup

> Ensure that removing repeated text does not break the narrative or the document’s hierarchy.

After you have stripped out filler and inserted tokens, read the document from start to finish. Check that each paragraph transitions smoothly, that headings still make sense, and that no dangling references remain. A quick checklist includes: (1) Does each section have a clear opening? (2) Are any pronouns left without antecedents because the removed text contained them? (3) Are token comments clear enough for a future writer? If any of these checks fail, reinstate a minimal amount of text to restore coherence. This verification step is crucial because downstream agents—designers, developers, or translators—rely on a well‑structured source to produce quality output.
