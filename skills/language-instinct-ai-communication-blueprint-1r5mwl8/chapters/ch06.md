# ch06 — Grammar as a Hidden Engine: Phrase Structure and Meaning

> Explains how the brain parses sentences into hierarchical phrases and why surface word order alone does not determine meaning.

When a listener hears a sentence, the brain builds a tree: words group into noun phrases, verb phrases, and larger clauses. The tree determines which auxiliary moves in a question, which noun receives agreement, and where focus falls. Errors arise when speakers assume a linear rule (e.g., “move the first auxiliary”) that conflicts with the phrase‑based rule. Because the algorithm is automatic, listeners rarely notice the underlying computation, but they will feel a sentence is “odd” if the structure violates expectations. For AI, this means that messages should respect the expected hierarchical cues—such as placing the main verb after the subject, using consistent tense markers, and aligning pronouns with their antecedents—so the listener’s hidden engine can operate smoothly.
