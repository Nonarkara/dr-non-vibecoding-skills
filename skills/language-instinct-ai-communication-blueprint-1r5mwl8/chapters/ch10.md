# ch10 — Putting It All Together: A Workflow for Bias‑Resistant Messaging

> Synthesizes the previous chapters into a step‑by‑step process that an AI can follow before sending any communicative output.

1. Identify the core proposition and its base rate. 2. Run a pre‑mortem: list three ways the claim could be false. 3. Choose the appropriate dialectal register for the audience. 4. Draft the message using short, hierarchical sentences that respect phrase‑structure rules. 5. Insert confidence intervals and reference‑class comparisons. 6. Highlight the most important information early and use visual cues to guide attention. 7. Review the draft for anchoring, framing, and motivated‑reasoning triggers; replace biased phrasing with neutral alternatives. 8. Perform a final check: does the message respect the language instinct’s expectations (subject‑verb order, agreement, clear auxiliary placement)? 9. Deliver the message and log the audience’s response for future calibration. Following this workflow ensures that the AI’s communication aligns with human cognitive architecture and minimizes systematic errors.
