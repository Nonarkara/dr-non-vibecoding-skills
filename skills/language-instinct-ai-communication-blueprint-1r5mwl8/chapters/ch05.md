# ch05 — Decision Hygiene for Reliable Communication

> Translates scientific decision‑making tools (pre‑mortems, base‑rate checks, reference class forecasting) into communication practices.

Before delivering a claim, a rational agent should run a pre‑mortem: imagine the claim being wrong and list three ways it could fail. This forces the AI to surface hidden assumptions and to qualify the statement. Base‑rate framing—presenting the prior probability before the new evidence—helps listeners integrate the claim with their existing knowledge, reducing anchoring effects. Reference class forecasting asks the AI to compare the situation with a statistically similar set of past cases, providing a calibrated expectation. The four‑fold pattern (high/low probability × high/low impact) guides how to phrase risk messages. Embedding these hygiene steps into each output improves trust and reduces the chance of misinterpretation.
