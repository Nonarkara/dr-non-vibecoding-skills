# ch03 — Condensing Repetition with Tokens

> Learn how to replace bulk repeated sentences with a single token or variable for future content insertion.

Once you have identified pure filler, the next step is to replace it with a concise token. A token is a short placeholder such as "{{CONTENT}}" that signals where real copy will go. This keeps the document DRY and makes later editing easier. The process is straightforward: (1) Delete all but the first occurrence of the repeated sentence, (2) insert a token in its place, and (3) add a comment explaining the token’s purpose. For example, the test document’s repeated line becomes "{{TEST_PARAGRAPH}}" after cleanup. Tokens also help automated tools—like content generators or translators—recognize where to inject or skip text. By using tokens, you preserve the document’s structure while eliminating unnecessary bulk.
