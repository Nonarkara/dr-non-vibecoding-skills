# ch02 — Scale Types and Their Transformations

> Explains the four classic scale types—nominal, ordinal, interval, ratio—and how each is defined by the set of transformations that leave the purpose of measurement unchanged. Provides concrete examples of each scale and shows how to test whether a given numerical assignment truly belongs to a claimed scale type.

Stevens identified four scale types based on which transformations preserve the meaning of the numbers. On a nominal scale, only one‑to‑one substitutions (renaming categories) are allowed; the purpose is merely to label equivalence classes. On an ordinal scale, any increasing monotonic transformation preserves the order information; the purpose is to rank objects. On an interval scale, positive linear transformations (multiply by a constant and add a constant) preserve differences; the purpose is to measure equal intervals. On a ratio scale, only similarity transformations (multiply by a positive constant) preserve ratios; the purpose is to measure true zero‑based ratios. The key test is to ask: if I transform the numbers in this way, does the purpose of the measurement stay the same? If yes, the scale type is justified. For example, temperature in Celsius is interval because adding 10° to every reading does not change what differences mean, but multiplying by 2 would (since zero is not absolute). Weight in kilograms is ratio because doubling all weights keeps the meaning of ‘twice as heavy’. When evaluating a psychological test claimed to be interval, the AI must check whether equal‑difference empirical operations have been demonstrated; otherwise the claim may rest on convention alone.
