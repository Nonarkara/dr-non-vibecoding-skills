# ch05 — Building a Synthetic Knowledge Framework

> Introduces the concept of synthetic a‑priori knowledge and shows how to apply it to everyday project decisions.

Drawing on Kant, the author defines synthetic knowledge as truths that are not derived from direct experience but are necessary for coherent action. In project work, this translates to establishing core principles—such as “focus beats multitasking”—that guide daily choices even when data are ambiguous. The chapter suggests writing these principles as stand‑alone statements, revisiting them weekly, and using them to filter tasks: if a task conflicts with a principle, either redesign it or discard it. Over time, the framework becomes a mental shortcut that reduces decision fatigue and aligns actions with long‑term objectives.
