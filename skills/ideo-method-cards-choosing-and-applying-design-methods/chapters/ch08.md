# ch08 — Synthesizing Insights: From Data to Concepts

> Shows how to turn raw observations into actionable design concepts using synthesis methods.

### Core Synthesis Methods
- **Affinity Diagrams** – Cluster raw quotes into themes.
- **Conceptual Landscape** – Map ideas across dimensions (e.g., need vs. feasibility).
- **Narrative Mapping** – Build user stories that connect insights.
- **Cognitive Maps** – Visualize mental models.

### Step‑by‑Step Synthesis
1. **Gather Raw Data** – From Look and Ask methods.
2. **Tag & Sort** – Use sticky notes or digital cards to label each datum.
3. **Cluster** – Group similar items; name each cluster.
4. **Prioritize** – Vote or rank clusters based on impact.
5. **Translate** – Convert top clusters into design concepts or problem statements.

### Deliverable
A **Synthesis Deck** containing theme headings, supporting quotes, and a set of concept sketches ready for the Try phase.
