# ch04 — Sequencing Methods Correctly

> Explains how to order methods from discovery to validation, preventing phase mismatches.

### Typical Flow
1. **Learn** – Secondary Research → Competitive Survey
2. **Look** – Fly on the Wall → Behavioral Mapping → Flow Analysis
3. **Ask** – Extreme User Interviews → Five Whys → Surveys
4. **Synthesize** – Affinity Diagrams → Conceptual Landscape → Narrative Mapping
5. **Try** – Experience Prototype → Paper Prototyping → Scenario Testing
6. **Implement** – Refine prototype → Production hand‑off

### Why Order Matters
Running a prototype before you have a clear set of user needs leads to irrelevant designs. Conversely, skipping synthesis after interviews wastes raw data.

### Recipe for Proper Sequencing
1. **Identify Current Phase** – Ask the AI what data exists.
2. **Select Next‑Phase Method** – Choose a method tagged for the next logical phase.
3. **Validate Output** – Ensure the deliverable feeds into the subsequent method’s inputs.
4. **Iterate** – If insights are insufficient, loop back to the previous phase.

Use this flowchart whenever the agent is unsure whether a method belongs early or late in the process.
