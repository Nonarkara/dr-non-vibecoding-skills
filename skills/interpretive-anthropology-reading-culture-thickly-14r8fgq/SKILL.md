## Core principles

- Culture is a web of meanings that actors weave through their everyday actions.
- Thick description means describing an action together with its context, symbolism, and the actor’s own interpretation.
- The emic perspective captures the insider’s view of meaning, while the etic perspective provides the outsider’s analytical lens.
- Symbols acquire meaning only within the network of cultural practices that surround them.
- Anthropological interpretation must stay open‑ended; it should never reduce a culture to a single rule or pattern.
- Fieldwork is the only way to access the lived experience that gives symbols their significance.
- Interpretation is a dialogue between the observed action and the interpreter’s conceptual tools, not a one‑way extraction of facts.
- Rituals are staged performances that reveal the hierarchy of values in a society.
- Every cultural description is provisional and must be revisable when new contextual data appear.

## Thick Description Workflow

**When to use:** When an AI needs to turn raw observation into a culturally meaningful account.

**Recipe:**

1. Record the action with sensory detail (who, what, where, when).
2. Ask the participant for their own explanation (emic statement).
3. Identify the symbols and rituals involved.
4. Place the episode within its historical and social context.
5. Write a narrative that weaves all layers together.

**Chapter:** ch02

---

## Emic Extraction

**When to use:** Whenever the system encounters a new cultural phrase or practice.

**Recipe:**

1. Locate the native term or phrase in the data.
2. Prompt the speaker (or a reliable informant) for its meaning in their own words.
3. Record the explanation verbatim.
4. Tag the entry with the speaker’s cultural category.
5. Use the tagged entry as the basis for further analysis.

**Chapter:** ch03

---

## Symbolic Meaning Mapping

**When to use:** When a recurring visual or verbal symbol appears across multiple events.

**Recipe:**

1. Collect all instances of the symbol.
2. Note the accompanying actions, emotions, and emic explanations.
3. Create a network diagram linking the symbol to its associated meanings.
4. Check the diagram against known cultural narratives.
5. Update the diagram as new instances are observed.

**Chapter:** ch04

---

## Avoiding Overgeneralization

**When to use:** When the AI detects a pattern that could be turned into a rule.

**Recipe:**

1. Verify the pattern across at least three distinct contexts.
2. Add contextual qualifiers (time, place, social status).
3. Present the pattern as a hypothesis, not a law.
4. Invite further data collection to test the hypothesis.
5. Revise or discard the pattern if contradictory evidence appears.

**Chapter:** ch07

---

## Contextual Disambiguation

**When to use:** When a symbol or phrase could have multiple meanings.

**Recipe:**

1. Identify all possible meanings from the glossary.
2. Examine the surrounding actions and participants.
3. Select the meaning that best fits the current context.
4. Record the chosen meaning with a note on alternative readings.
5. Store the decision for future reference.

**Chapter:** ch09

---

## Ritual Textual Analysis

**When to use:** When interpreting a ceremony or public performance.

**Recipe:**

1. Break the ritual into phases (opening, climax, closure).
2. Annotate each phase with emic explanations and symbols.
3. Map each phase to the broader cultural values it enacts.
4. Compare the structure to known ritual typologies.
5. Summarize the ritual’s cultural significance in a thick description.

**Chapter:** ch08

---

## Iterative Fieldwork Loop

**When to use:** When the AI’s initial description feels incomplete.

**Recipe:**

1. Flag the description as provisional.
2. Generate specific follow‑up questions for informants.
3. Collect additional data (audio, video, interview).
4. Integrate the new data into the existing thick description.
5. Re‑evaluate the interpretation for coherence.

**Chapter:** ch06

## Cheatsheet

# Cheatsheet

Imperative decision rules from the source, grouped by category. Each is the kind of sentence you would write on an index card.

## process

- Before you generalize, present the actor’s own explanation.
- Record sensory details first, then add interpretation.
- Use metadata (time, place, participants) for every cultural note.
- Ask the informant ‘why’ before you ask ‘how’.
- If a symbol’s meaning is ambiguous, list all plausible meanings with contextual notes.
- Interpretation is a dialogue, not a monologue—always leave room for revision.
- Always attach a confidence score to any interpretive claim.

## culture

- Never reduce a culture to a single rule; always keep qualifiers.
- When in doubt, prioritize the actor’s own categorization over academic labels.
- Never assume that a single observation represents the whole culture.

## writing

- Treat symbols like words in a sentence: meaning depends on surrounding symbols.
- Keep the emic statement verbatim; never paraphrase before storage.
- Separate description (what happened) from analysis (what it means).

## analysis

- If a pattern appears in fewer than three contexts, label it a hypothesis.
- If a ritual’s climax is missing, treat the description as incomplete and seek more data.

## design

- When a ritual repeats, map its phases before interpreting its meaning.
- Use a network diagram to visualize symbol relationships before writing conclusions.

## life

- Fieldwork is not optional; treat any dataset without context as low confidence.

## general

- When you encounter a new cultural term, add it to the glossary immediately.
- If a cultural act feels familiar, double‑check that you’re not projecting your own bias.
