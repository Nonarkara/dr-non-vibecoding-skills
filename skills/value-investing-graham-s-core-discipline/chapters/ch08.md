# ch08 — Practical Application Checklist

> Provides a step‑by‑step routine the agent can follow when evaluating a security: estimate value, compute margin, check temperament, decide, and record.

A repeatable process reduces error and creates a learning loop. Step 1: Gather financial data and compute a conservative intrinsic value (e.g., net current asset value, normalized earnings × appropriate multiplier). Step 2: Calculate the margin of safety as (value − price) / value. Step 3: Verify that the margin meets a pre‑set threshold (e.g., ≥20 %). Step 4: Run a temperament check—ensure the decision is not driven by fear, greed, or social proof. Step 5: If all checks pass, record the rationale, the estimated value, the price, and the margin. Step 6: Set a review schedule (e.g., quarterly) to reassess fundamentals and price. If the price rises to intrinsic value or the margin erodes, consider selling; if fundamentals worsen, exit regardless of price.
