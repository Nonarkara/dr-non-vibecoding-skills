# ch01 — Reduce

> The simplest way to achieve simplicity is through thoughtful reduction. This chapter explains how to shrink, hide, and embody value when removing functionality, using examples like DVD players, technology miniaturization, and quality cues.

Start by asking what can be removed without hurting the core purpose. If a feature is rarely used, consider taking it away—like stripping a DVD player down to just a Play button. When removal alone feels too stark, apply the three‑step ‘she’ method. First, shrink the object: make it physically smaller or visually lighter so expectations lower and the user feels more forgiving of quirks. Second, hide the remaining complexity behind doors, menus, or gestures that only appear when needed, as a Swiss army knife or a clamshell phone does. Third, embody the lost value by increasing real or perceived quality—better materials, finer craftsmanship, or clear signals like a ‘3 CCD’ label—so the user feels the product is still worth having. Balance is key: remove too much and the tool becomes useless; remove too little and complexity remains. Use reduction as the first move, then decide whether to shrink, hide, or embody to keep the design both simple and valuable.
