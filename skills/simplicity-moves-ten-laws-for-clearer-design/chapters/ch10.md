# ch10 — The One

> The essence of simplicity is subtracting the obvious and adding the meaningful. This chapter brings together the previous laws into a single guiding move for any design challenge.

Look at your design and ask what is obvious—features, steps, or elements that users expect simply because they have always been there. Subtract those obvious parts if they do not add real value. Then ask what is meaningful to the user in this context: what goal, feeling, or outcome truly matters. Add back only those meaningful elements, even if they add a little complexity. The result is a design that feels lean because the noise is gone, yet rich because the signal remains. Use this move as a final check after applying any of the other laws: have you removed the obvious and inserted the meaningful? If yes, you have achieved the core of simplicity.
