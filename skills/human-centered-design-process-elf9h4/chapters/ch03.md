# ch03 — Framing the Design Challenge

> Shows how to turn vague problems into actionable, impact‑driven questions that guide ideation.

A well‑framed challenge is a single sentence that is solution‑oriented, impact‑focused, and context‑aware. Start by writing a draft question, then test it against three filters: Does it aim for measurable impact? Does it allow many possible solutions? Does it respect known constraints (budget, geography, culture)? Revise the wording until the team can quickly list five distinct solutions in a few minutes—if they can, the frame is likely strong. The final frame should read like a "How might we…" question that invites creativity while keeping the target audience front‑and‑center. This chapter provides a step‑by‑step worksheet and examples, enabling the AI to generate or refine challenge statements automatically.
