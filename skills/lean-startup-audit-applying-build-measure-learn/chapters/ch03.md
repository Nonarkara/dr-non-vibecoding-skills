# ch03 — Measuring Real User Behavior

> Covers the metrics and data‑collection techniques needed to turn user actions into meaningful signals for the loop.

Measurement is the bridge between building and learning. Instead of vanity metrics like page views, the Lean Startup focuses on actionable metrics that directly test the hypothesis. Common metrics include activation rate (the percentage of users who complete the core action), retention cohorts, and revenue per user. The chapter explains how to set up analytics tools, define events, and segment users to isolate the behavior that matters. It also introduces *split testing* (A/B testing) as a way to compare two variations of an MVP against the same metric. Data should be collected continuously, but analysis is done in short cycles—often weekly—to keep the loop moving. The chapter stresses the importance of *cohort analysis* to see how early adopters behave over time, revealing whether the product is gaining traction or losing interest.
