# ch04 — Minimum Viable Product (MVP)

> An MVP is a version of a product with just enough features to gather the most critical feedback from early customers.

The Minimum Viable Product (MVP) is a crucial element of the Lean Startup approach. It's not about creating a fully functional product; it’s about building the simplest possible version that allows you to test your riskiest assumptions. The goal is to learn quickly and cheaply, minimizing wasted effort.
