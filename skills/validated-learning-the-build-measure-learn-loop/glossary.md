# Glossary

Terms and named ideas from the source, anchored to the chapter that explains them.

| Term | Definition | Chapter |
| --- | --- | --- |
| **MVP** | Minimum Viable Product – the simplest version of a product that allows you to test your riskiest assumptions. | ch04 |
| **Validated Learning** | The process of learning through experimentation and data analysis, rather than relying on assumptions. | ch01 |
| **Build-Measure-Learn Loop** | An iterative process of building a product, measuring its performance, and learning from the results. | ch01 |
| **Pivot** | A strategic course correction based on validated learning. | ch05 |
| **Vanity Metric** | A metric that looks good but doesn’t provide actionable insights. | ch05 |
| **Actionable Metric** | A metric that provides insights you can use to make informed decisions. | ch05 |
| **Innovation Accounting** | A framework for measuring progress in a startup based on validated learning. | ch08 |
| **Assumption** | An unproven belief or hypothesis that needs to be tested. | ch01 |
| **Experiment** | A controlled test designed to gather data and validate assumptions. | ch08 |
| **Framework** | A structured approach or system for problem-solving. | ch01 |
