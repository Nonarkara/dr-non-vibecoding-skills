# ch08 — Error Types and Prevention

> Defines slips, mistakes, mode errors, and capture errors, and offers strategies to reduce each through design.

Errors fall into four categories. Slips occur when the user intends the correct action but executes the wrong one—pressing the wrong button due to proximity. Mistakes happen when the user’s plan is wrong, often because the conceptual model is inaccurate. Mode errors arise when the same control does different things in different modes, and the user is unaware of the current mode. Capture errors happen when a familiar pattern overrides the intended action, such as automatically opening a familiar app instead of a new one. To prevent slips, increase spacing between controls and add distinct signifiers. To avoid mistakes, provide a clear conceptual model and constraints that guide the correct plan. Mode errors are reduced by making the mode visible—e.g., a highlighted indicator. Capture errors are mitigated by designing unique signifiers for each context and avoiding overly familiar patterns that mask the intended action.
