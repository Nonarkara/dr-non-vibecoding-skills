# ch03 — Mapping and Natural Mapping

> Shows how to align controls with their effects using spatial relationships, cultural conventions, and Gestalt principles to make actions intuitive.

Mapping is the relationship between a control and the result it produces. Natural mapping uses spatial analogies that the user can instantly recognize. For example, a row of light switches placed in the same order as the lights they control lets a user locate the correct switch without thinking. Cultural conventions also guide mapping: moving a slider up usually increases volume, while moving it down decreases it. Gestalt principles—such as proximity and similarity—help group related controls together, reinforcing the mapping. When mapping is arbitrary, users must learn a new relationship, increasing cognitive load and error risk. Designers should ask, "If the control were placed on the device, would the user intuitively know what it does?" If the answer is no, redesign the layout or add signifiers that clarify the mapping.
