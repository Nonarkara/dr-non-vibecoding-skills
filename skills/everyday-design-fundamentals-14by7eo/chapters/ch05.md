# ch05 — Constraints and Discoverability

> Shows how physical, logical, and cultural constraints limit user actions and help them discover correct usage without trial‑and‑error.

Constraints are limits that prevent incorrect actions. Physical constraints—such as a plug that only fits one way—force the correct orientation. Logical constraints—like disabling a "Save" button until required fields are filled—guide the user through a workflow. Cultural constraints rely on shared conventions; for example, a red button is commonly associated with stopping or danger. By combining constraints with clear signifiers, designers make the correct action the path of least resistance. Discoverability improves when constraints are visible: a recessed slot shows where a key belongs, and a magnetic latch signals that the door can be closed without force. When constraints are hidden, users must guess, leading to slips and mistakes.
