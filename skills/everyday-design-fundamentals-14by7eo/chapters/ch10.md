# ch10 — Integrating Principles: A Design Checklist

> Combines all previous concepts into a practical, step‑by‑step checklist that can be applied to any new product.

When starting a new design, follow this integrated checklist: 1) Identify all possible actions (affordances) and make the relevant ones visible. 2) Add signifiers that tell the user where and how to act. 3) Arrange controls so that their spatial relationship mirrors the effect (natural mapping). 4) Define constraints that block incorrect actions. 5) Build a simple conceptual model that users can infer from the device’s shape and signifiers. 6) Provide immediate, informative feedback for every interaction. 7) Test with first‑time users and observe the seven‑stage action cycle; fix any gaps in execution or evaluation. 8) Review error types and add safeguards for slips, mistakes, mode, and capture errors. 9) Iterate until the product works for a user who has never seen it before. This checklist ensures that all core principles are addressed before the product reaches production.
