# ch01 — What Is a Pattern Language?

> Defines the concept of a pattern, its format, and why it matters for design.

A pattern language is a catalogue of design moves that capture a problem that recurs in the built environment and a core solution that works across contexts. Each pattern follows a fixed format: a picture, an introductory paragraph, a problem statement, a headline, a detailed problem description, a solution expressed as an instruction, a diagram, and a closing paragraph that ties the pattern to larger and smaller patterns. The purpose of this format is two‑fold: to show how each pattern fits into a larger network and to give designers enough detail to judge and adapt the solution themselves. Patterns are not isolated rules; they are nodes in a network that together form a language for creating towns, buildings, and interiors. By learning the language, designers can combine patterns in countless ways, producing environments that feel alive and human‑scaled.
