# ch03 — Reading the Sequence as a Base Map

> Shows how the linear sequence of patterns serves as a roadmap for projects.

Although the pattern language is a network, the book presents the patterns in a linear sequence that moves from the biggest structures to the tiniest details. This sequence acts as a base map: designers can follow it to ensure they address the most fundamental patterns first and then drill down to finer grain decisions. The sequence is not the only possible path, but it captures a logical progression that mirrors how towns and buildings grow over time. By using the sequence as a scaffold, designers can select relevant patterns, keep them in roughly the same order, and still adapt the order to suit local conditions. The map helps maintain the integrity of the hierarchy while allowing flexibility.
