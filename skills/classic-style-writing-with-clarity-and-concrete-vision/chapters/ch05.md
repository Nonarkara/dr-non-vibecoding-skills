# ch05 — Zombie Nouns and Nominalizations

> Identifies nominalizations as lifeless nouns that hide agents. Teaches how to revive them into active verbs.

Nominalizations add suffixes like –tion, –ment, –ance, turning verbs into nouns (e.g., *affirmation*). These “zombie nouns” strip away the doer, making sentences harder to picture. Replace them with the original verb: *We affirmed the hypothesis* instead of *The affirmation of the hypothesis*. This restores agency and visual clarity. In some cases, a nominalization is useful for cohesion, but the default should be a verb. The same applies to adjective‑derived nouns (e.g., *contributive* → *contributes*).
