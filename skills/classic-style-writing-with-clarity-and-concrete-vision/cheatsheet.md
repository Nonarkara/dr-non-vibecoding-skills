# Cheatsheet

Imperative decision rules from the source, grouped by category. Each is the kind of sentence you would write on an index card.

## writing

- If a sentence is about a thing, use a noun.
- If a sentence is about what someone did, use a verb.
- When a sentence feels hard to parse, look for buried verbs hidden in nominalizations.
- Replace zombie nouns with their original verbs.
- Use active voice to keep the reader’s gaze on the doer.
- Use passive voice only to hide an irrelevant or distracting agent.
- Limit hedges to statements that truly need qualification.
- When you must hedge, add a brief explanation of the limitation.
- Swap stale clichés for fresh, literal descriptions.
- If you use an idiom, ensure its literal image matches your context.
- Choose words whose sound matches their meaning (phonesthetics).
- Reserve uncommon words for moments when they add precision or memorable sound.
- Avoid using more than two adjectives in a row; let the noun do the work.
- Never start a paragraph with “In this section we will…”, let the first sentence be the content.
- If a sentence contains a passive construction, ask whether the agent matters; if not, keep it passive.
- When describing a process, use verbs that convey motion (e.g., *drift*, *burst*, *collapse*).
- Replace abstract nouns with concrete verbs to restore agency.
- If a paragraph feels heavy, cut any metadiscourse that does not aid comprehension.
- Use first‑person pronouns when they clarify perspective; avoid them only when they add unnecessary distance.

## process

- Ask yourself: What does the reader need to know before this sentence?
- Show a concrete example before explaining an abstract idea.
- Keep signposts to a single transition word or question.
- Read your prose aloud; if it trips, rewrite for smoother rhythm.
- Before publishing, run the 10‑step classic‑style checklist.

## general

- When you think of a word, say it aloud; if it feels wrong, choose a different one.
