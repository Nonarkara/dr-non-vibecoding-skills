# ch06 — Aphorisms as Micro‑Tasks

> Shows how to turn concise insights into actionable steps that move a larger project forward.

Aphorisms are presented as distilled observations that can be unpacked into concrete actions. For example, the aphorism “quality over quantity” becomes a checklist: (1) limit daily word count, (2) edit one paragraph for clarity, (3) discard any filler. The author recommends keeping a running “Aphorism Bank” where each entry is tagged with a project area (research, teaching, personal growth). When a block appears, select an aphorism that resonates, expand it into a 5‑minute task, and log the result. This habit turns abstract wisdom into measurable progress.
