## Core principles

- Writing every day creates a low‑friction habit that keeps the larger research project alive.
- Your physical environment determines the quality of focus; moving to a quiet, natural setting can reset productivity.
- A PhD or any long‑term credential should be pursued only if it serves a deeper learning goal, not as a status marker.
- Synthetic knowledge—ideas that are true before experience—guides decision‑making when data are noisy or incomplete.
- Aphorisms are distilled insights that can be turned into actionable micro‑tasks for a larger project.
- Project milestones are more reliable than vague intentions; they should be reviewed weekly and adjusted.
- Balancing mental health with work output requires explicit breaks and reflection periods built into the schedule.

## Daily Writing Sprint

**When to use:** When you need to keep a habit alive and generate content for a larger project.

**Recipe:**

1. Set a timer for 10 minutes.
2. Write whatever comes to mind—no editing.
3. Pick one sentence and turn it into an aphorism.
4. Log the aphorism in your “Aphorism Bank”.

**Chapter:** ch01

---

## Environment Switch for Focus

**When to use:** When urban noise is lowering your productivity.

**Recipe:**

1. Identify a quiet location you can access weekly.
2. Pack only the tools needed for the task (laptop, notebook).
3. Work there for a minimum of 2 hours without digital interruptions.
4. Write a brief summary of what was accomplished before leaving.

**Chapter:** ch02

---

## Milestone Review Loop

**When to use:** To keep long‑term projects on schedule and avoid drift.

**Recipe:**

1. Define 3‑5 concrete milestones for the next month.
2. At the end of each week, compare actual output to the milestones.
3. Adjust the next week’s tasks to close any gaps.
4. Record the adjustment in a project log.

**Chapter:** ch03

---

## PhD Decision Filter

**When to use:** When deciding whether a doctorate aligns with your career goals.

**Recipe:**

1. List the top 5 skills you need for your desired role.
2. Mark which of those the PhD will teach directly.
3. If fewer than 3 skills are covered, explore alternatives (MOOCs, apprenticeships).
4. Write a short justification for your final decision.

**Chapter:** ch04

---

## Aphorism‑to‑Action Loop

**When to use:** When you have a collection of insights but need concrete progress.

**Recipe:**

1. Select an aphorism that resonates with the current challenge.
2. Break it into a 5‑minute micro‑task (e.g., edit one paragraph, email a mentor).
3. Complete the task and note the outcome.
4. If the outcome is useful, add a related aphorism to the bank.

**Chapter:** ch06

---

## Mental‑Health Reset Cycle

**When to use:** During periods of burnout or intense stress.

**Recipe:**

1. Schedule a 5‑minute breathing exercise at the start of each workday.
2. Plan a weekly social activity that is unrelated to work.
3. Every month, take a half‑day retreat in a new environment to reflect on goals.
4. After each reset, write a short note on how focus or mood changed.

**Chapter:** ch07

## Cheatsheet

# Cheatsheet

Imperative decision rules from the source, grouped by category. Each is the kind of sentence you would write on an index card.

## process

- Write for 10 minutes every day, no matter what.
- Schedule a monthly retreat to review purpose and progress.
- Use a decision filter: if a task fails two criteria, drop it.

## life

- If the room feels noisy, move to a focus sanctuary.
- When you feel stuck, pause for a 5‑minute breath reset.

## project

- Check weekly: are you on track for your next milestone?

## career

- Ask: does a PhD teach the exact skill I need? If not, skip it.

## writing

- Turn every aphorism into a 5‑minute concrete task.

## code

- Timebox every work block; stop when the timer rings.

## general

- Document each pattern you adapt; treat it as a reusable asset.
