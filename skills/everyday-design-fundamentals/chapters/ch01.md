# ch01 — Affordances and Perceived Affordances

> Explains the difference between real affordances and those that are merely visible. Shows how designers can expose hidden affordances and avoid misleading cues.

An affordance is any property of an object that makes a particular action possible. A door that can be pushed has a push affordance; a knob that can be turned has a turning affordance. Not all affordances are obvious—some are hidden behind a flat surface or a concealed latch. Designers must make the relevant affordances perceivable, either by shaping the object (a flat plate that invites pushing) or by adding signifiers that highlight the action (a handle that signals pulling). When a perceived affordance does not match the real affordance, users are misled; a decorative bar that looks like a handle but does not move is a classic mistake. To avoid this, expose the true affordance through shape, texture, or movement, and test whether users can discover the action without instructions. Visible affordances reduce the need for labels, speed up learning, and lower error rates.
