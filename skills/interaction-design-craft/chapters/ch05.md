# ch05 — Browser‑Style Navigation: The Smalltalk Browser

> Tesler’s Smalltalk browser showed how to navigate complex hierarchies with three panes—classes, methods, and code—each with its own scroll bar. The pattern later influenced web browsers, debuggers, and database front‑ends.

After the success of Gypsy, Tesler joined Alan Kay’s Smalltalk team and was tasked with building a code browser. He imagined a window split into three columns: a list of classes, a list of methods for the selected class, and the source code for the selected method. Each pane got its own scroll bar so users could browse before committing to a selection. He also made the code pane editable using the standard Smalltalk editing commands (drag‑through, cut, paste). The browser spread quickly through PARC, was later improved by Dan Ingalls who added categorical panes, and became the classic Smalltalk browser. Tesler noted that the same metaphor—lists plus detail view—could be applied to other domains: browsing files, database records, or web pages. The key design principle is to separate navigation (where to look) from manipulation (what to do there), letting users scan large spaces with simple scroll actions before diving into detail.
