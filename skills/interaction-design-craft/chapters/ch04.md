# ch04 — Interaction Primitives: Double‑Click, Cut/Paste, Cursor Placement

> Three small inventions—double‑click to select a word, the cut/paste command pair, and the cursor positioned between characters—together removed modes, reduced keystrokes, and made text manipulation feel direct and error‑free.

While working on Gypsy, Tesler wrestled with a three‑button mouse. He wanted a single button that could work with tablets and touch screens, but users kept hitting the wrong button. Tim Mott suggested the double‑click: two rapid clicks in the same spot select a word, three select a sentence. Tesler tried it with secretaries and found it felt right immediately, confirming the idea through observation rather than debate. For moving text, Tesler adopted Kanerva’s method: select the target, issue ‘escape‑d’ to delete, then move the cursor and type ‘escape‑o’ to undo, or press ‘L’ to insert from a buffer. He realized the same idea could serve both delete and insert if he renamed the operations ‘cut’ and ‘paste’, cutting the keystrokes from six to two. Finally, he solved the insertion‑point problem by placing the cursor between characters rather than on them, using a blinking vertical line (later a caret) to show where new text would appear. These three primitives together created a modeless, low‑error editing experience that became standard across personal computers.
