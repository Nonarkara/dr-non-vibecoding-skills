# ch07 — Designing Defaults and Reducing Friction

> Shows how to set defaults, lower effort, and shape option layout to make the desired path the easiest.

Defaults are the pre‑selected options that users receive if they do nothing. To nudge effectively, set the preferred outcome as the default and make opting out require extra steps. Reduce friction on the target path by minimizing clicks, simplifying forms, and using clear visual cues. Conversely, increase friction on less‑desired options by adding confirmations or extra fields. This leverages both loss aversion (users avoid losing the default) and the tendency to follow the path of least resistance.
