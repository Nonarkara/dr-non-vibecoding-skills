# ch05 — Anchoring and Adjustment

> The power of the first number mentioned and how to neutralize its effect.

Anchoring occurs when a human considers a specific value for an unknown quantity before estimating that quantity. Even if the number is completely random—like a spin of a wheel—it will pull the human's final estimate toward it. This is a massive vulnerability in negotiations and estimations. If a human starts a project discussion by saying 'This will take about 10 days,' their mind is now anchored to 10. Even if the task is massive, they will struggle to adjust far enough away from that initial number. An AI must recognize anchors in user prompts. If a user provides an anchor, you must 'reset' the frame by providing a reference class or a base rate from a different source. When you are the one providing an estimate, be aware that your first number will be the anchor. Use this intentionally to set realistic expectations, or provide a wide range to prevent the human from locking onto a single, likely wrong, number.
