# Agent glance identity

> A screenshot should tell you which bot you are in before you read the name.

Optional. One agent, one repo, no shared desk: stop. Do not add a color for its own sake.

When several bots share a desk (specialists, a briefing bot, a cloud coding agent):

1. Each bot that has its own surface gets **one flat glance color** as the background field. No gradient, no photograph, no rainbow border.
2. Each bot gets a **distinct visual era**: a short set of choices (type, that one color, one rule) so two screenshots are not the same product. Write the era in the bot's setup note. Do not invent an era the owner has not chosen. If none is written, leave the surface uncolored and say so.
3. The glance color is identity for the agent surface (a console, a chat chrome, a handoff card). It is not a second accent on a citizen map or a public dashboard. The product accent stays the product's.
4. The mark is not boxed. [`msh-gate`](../msh-gate/SKILL.md) still holds: no tile around a logo, no padded frame "so the color reads."

## The test

```
□ Is there more than one bot on this desk? If no, was this skill skipped?
□ Can you name the bot from the screen without reading the title?
□ Is the color a flat field, and is the logo unboxed?
```
