# ch05 — Questioning Tradition in Design

> Encourages designers to treat established practices as hypotheses to be tested rather than immutable rules.

The author challenges the notion that traditions—whether coffee‑shop meetings or legacy UI patterns—are inherently good. He argues that tradition persists because it is convenient, not because it solves current user problems. In design, this translates to a "tradition‑audit" step: list every assumed best practice, then ask what user need it fulfills today. If the answer is weak, prototype an alternative. The text’s discussion of coffee culture in Shanghai illustrates how a practice can become a status symbol, divorced from its original functional purpose. By applying the same scrutiny, designers can avoid unnecessary complexity and focus on solutions that truly add value. This mindset also helps identify hidden failure modes that arise when a tradition no longer matches user expectations.
