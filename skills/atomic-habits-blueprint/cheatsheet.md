# Cheatsheet

Imperative decision rules from the source, grouped by category. Each is the kind of sentence you would write on an index card.

## design

- If a habit feels invisible, add a bright sticky note where you act.
- Store junk food on the top shelf; keep healthy snacks at eye level.
- If a habit feels hard, remove one step until it feels easy.

## process

- Pair any new habit with a coffee break to boost attraction.
- If a cue is ambiguous, rename it with a verb and a time (e.g., "Morning‑Run").
- When a habit stalls, change the environment cue before changing the habit itself.

## life

- When you miss a day, do a micro‑step the next day instead of restarting.
- When designing a new habit, ask: "Does this make me the person I want to be?"

## code

- Make the first 5 minutes of any habit the only required part.
- Use a timer to limit habit execution to 2 minutes; extend only after consistency.

## general

- Reward yourself with a 30‑second stretch after each completed task.

## writing

- Log every habit in a single column; visual progress beats scattered notes.
