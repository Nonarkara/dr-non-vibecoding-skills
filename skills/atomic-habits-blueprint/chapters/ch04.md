# ch04 — The Habit Loop: Cue, Craving, Response, Reward

> Describes the four‑stage habit loop and how to manipulate each component to install or dismantle habits.

## The Habit Loop

1. **Cue** – The trigger that tells the brain to start a behavior. It can be time, location, emotional state, or preceding action. Make cues obvious for good habits and hide them for bad ones.
2. **Craving** – The motivational desire that drives the behavior. Increase craving by pairing the habit with a pleasant stimulus (e.g., listening to favorite music while coding).
3. **Response** – The actual action. Reduce friction to make the response easy; increase friction for unwanted habits (e.g., store junk food out of sight).
4. **Reward** – The outcome that satisfies the craving. Provide immediate, tangible rewards for new habits; delay or remove rewards for bad habits.

Understanding each stage lets an AI diagnose why a habit fails. If a cue is missing, the assistant can add a reminder. If the craving is weak, it can suggest a rewarding pairing. By systematically adjusting the loop, the assistant can engineer habit formation or extinction with precision.
