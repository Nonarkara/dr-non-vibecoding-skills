# Patterns

Reusable moves extracted from the source. Each is a recipe — context, then steps, then the chapter to read for the full argument.

## Cue Amplification

**When to use:** When a desired habit never starts because the trigger is unnoticed.

**Recipe:**

1. Identify the exact moment or location the habit should begin
2. Place a visual or auditory cue in that spot
3. Pair the cue with a distinct color or sound
4. Test for consistency over a week and adjust visibility as needed

**Chapter:** ch04

## Temptation Bundling

**When to use:** When motivation is low for a new habit.

**Recipe:**

1. Select a habit you want to build
2. Choose an enjoyable activity you already do
3. Only allow the enjoyable activity after completing the habit
4. Track completion and reward with a simple log

**Chapter:** ch02

## Micro‑Step Scaling

**When to use:** When a habit feels too big and leads to procrastination.

**Recipe:**

1. Break the habit into the smallest possible action
2. Perform that micro‑action for two minutes
3. Gradually increase duration by 10 % each day
4. Celebrate each incremental win with a quick note

**Chapter:** ch03

---

## Environment Hide‑Bad

**When to use:** When a bad habit is triggered by easy access (e.g., snacks, phone).

**Recipe:**

1. Locate the item that cues the bad habit
2. Move it out of sight or lock it away
3. Replace it with a neutral object
4. Create a new cue for a good habit in the same spot

**Chapter:** ch05

---

## Stacked Habit Integration

**When to use:** When you have an existing routine and want to add a new behavior.

**Recipe:**

1. List a reliable existing habit
2. Formulate a statement: "After X, I will Y"
3. Practice the stack for 21 days
4. Adjust Y’s difficulty if the stack fails

**Chapter:** ch05

---

## Reward Immediate Feedback

**When to use:** When a habit feels unrewarding and drops off.

**Recipe:**

1. Define a concrete, quick reward for completing the habit
2. Deliver the reward instantly (e.g., checkmark, point, short break)
3. Log the reward in a habit tracker
4. Review reward effectiveness weekly and tweak if needed

**Chapter:** ch02
