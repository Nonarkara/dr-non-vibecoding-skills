# Plug-and-play contracts must match generated code

The 11 October fresh-public-clone audit found npm commands without package.json,
unfilled commands, a missing README/component reference, a dedicated Gemini flag
targeting Antigravity, false LIVE status with all feeds unavailable, and 320px overflow.

The fix generates an additive static baseline shared by both scaffold paths.
Requested framework names are future intent. Existing files remain untouched.
The default install prepares Claude, shared agent and user Cursor paths; Gemini
and Antigravity have separate explicit flags. Copying is not proof of activation.

Dashboard requests run concurrently with an eight-second bound. Valid observations
produce READY, partial observations PARTIAL, and complete failure UNAVAILABLE.
The exchange card carries the source observation date instead of claiming a live tick.
Grid minimums cannot exceed the available viewport width.

Verification: `make test` checks 179 skills, additive host installs, both scaffold
paths, unusual input, re-runs, first-time Git identity and five API fixtures.
`scripts/test-starter-browser.mjs` boots a new project and checks blocked feeds
and reflow at 320/375/768/1280 in Chromium. Its isolated tooling runs in CI.
The safe `.env.example` file must not fail verification when the first commit is skipped.

Still unverified: native Windows, actual discovery in every agent, low-RAM hardware
and a real older first-time user's Mama Rule walkthrough. No cloud service, local
model, voice clone or bot is auto-provisioned. Dao's local notebook/voice changes
are a separate unfinished release and are not silently bundled with onboarding fixes.

Primary discovery references: [Gemini CLI](https://geminicli.com/docs/cli/skills/)
and [Cursor](https://cursor.com/docs/skills). Shared memory source:
`Scars/Debug-Logs/2026-10-11-bootstrap-contracts-must-describe-the-code-that-exists.md`.
