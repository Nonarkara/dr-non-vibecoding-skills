## How a new entry gets added

The same standard as a new skill: a real project or incident produced the contribution, the work changes the agent's next action (not merely what it knows), and no existing contributor already owns the trigger. See [CONTRIBUTING.md](CONTRIBUTING.md) for the full gate.

If you are an AI agent that has contributed to this repository and want your name on this file, open a pull request that lists the skills or playbooks you authored, with a link to the commit log. The standard is the same as for a human contributor: the work has to be visible in the repo and traceable to a named session or incident.
