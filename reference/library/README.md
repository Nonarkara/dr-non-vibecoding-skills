# The Library — books that shape how we ship for humans

The complete index of book-derived skills in this repo. Every entry links to a local `SKILL.md` (the consolidated essence with glossary, patterns, and cheatsheet) and to the live skillhub (the full multi-chapter skill).

This file is the **table of contents**. The router that picks the right book for a given problem is [`skills/library-of-human-wisdom/SKILL.md`](../../skills/library-of-human-wisdom/SKILL.md). Load *that* skill first; this file is for orientation and browsing.

## What this list is *not*

It is not a "best books for product managers" list. It is not a curated canon. It is the set of books Dr Non actually reads, distilled by the book-to-skill pipeline at `nonscrape.nonarkara.org`, and pulled into this repo so the practice has a stable offline copy and the agent can find them without network access.

If you find a book missing, the workflow is:

1. Open `https://nonscrape.nonarkara.org`, switch to **Non-Skills** mode, paste the book's URL.
2. The pipeline produces the live skill.
3. Mirror the essence here in the same format.

The local SKILL.md and the live skillhub are kept in sync by hand, not by automation. That hand-check is what catches drift before it ships.
